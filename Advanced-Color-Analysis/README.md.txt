## 🚀 Project Overview
This system uses Python, OpenCV, and NumPy to create an interactive computer vision application that detects color values from images in real time. By listening for single-click inputs on a graphical display canvas, the program instantly maps pixel vector locations and extracts numerical signatures across different color space representations.

## 🛠️ System Core Features
- **Instant Vector Resolution:** Maps user mouse coordinate matrices to accurate pixel arrays instantly.
- **Dual-Space Metric Extraction:** Translates standard image data into both RGB (Red, Green, Blue) and HSV (Hue, Saturation, Value) numerical structures.
- **On-Demand Workspace Capture:** Features a built-in shortcut key (`s`) that captures the current frame configuration and exports it directly to the local drive for verification.
- **Clean Framework Lifecycle:** Integrates a quick exit option (`q`) that manages clean system de-allocations and safely terminates UI window frames.
